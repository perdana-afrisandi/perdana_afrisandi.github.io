Why My Approach Stands Out

The "Trusted Analytics + Semi-AI" Advantage

Unlike standard portfolios that only show static charts, every project I build integrates three enterprise pillars that prevent "Garbage-In, Garbage-Out" decisions.

01

Data Quality (DQ) Gate First

Before calculating any business KPI, my pipelines run automated SQL validation rules (checking null drift, primary key duplicates, cross-table reconciliation, and schema parity). Stakeholders get a Data Trust Score alongside their dashboard.

Deterministic Semi-AI Chatbot

Pure LLMs hallucinate numbers. My Semi-AI Assistant uses Intent Routing + Parameterized SQL Templates + Python Math to compute 100% exact figures, then uses AI strictly as a narrative layer to explain root causes and action items to business users.

Root-Cause to P&L Simulation

Every analysis moves beyond "What happened?" to "Why did it happen, who owns the action, and how much Rp/USD will we save?"—backed by transparent baseline vs. incremental formulas.
